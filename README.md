# 计时闹钟

一个轻量、明亮的移动端 PWA：正计时、倒计时、番茄钟与今日计划。

## 功能

- 正计时：事项名称、暂停/继续、分段记录
- 倒计时：快捷时长和自定义时长
- 专注节奏：25 分钟专注 / 5 分钟休息
- 今日计划：预设计划时长、记录实际用时、勾选完成
- PWA：可在手机浏览器中添加到主屏幕使用

## 本地运行

使用任意静态服务器托管 `dist` 目录，例如：

```bash
python -m http.server 4173 --directory dist
```

随后打开 `http://localhost:4173`。

## 数据说明

计划、计时和统计数据仅保存在用户自己的浏览器本地，不会上传或与其他用户共享。
